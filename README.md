# Lightning market data

Closing prices that the [Lightning](https://lightningeg.com) personal finance app downloads, one folder per
market (`index.json` lists them). A collector updates them after each market closes.

Only data whose source allows republishing is published here, and each folder names its source in its
`manifest.json`.

| Folder | Prices | Source |
|---|---|---|
| `fx` | Official exchange rates, in Egyptian pounds | Central Bank of Egypt (cbe.org.eg) |
